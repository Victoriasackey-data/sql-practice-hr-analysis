# Practice SQL project:
Do employees who resign work high overtime more often than those who stay? 
This post is a practice project I revised.
I counted someone as having high overtime if they spent 3 months or more in the top quarter of overtime hours  in a calendar year.
I found that resigned employees had a lower high-overtime rate  (47.62%) compared to active employees (64.90%).
Only 42 employees resigned, compared with 208 active employees. The rate for resigned employees is less reliable.
The data did not support the idea that overtime drives resignation.
